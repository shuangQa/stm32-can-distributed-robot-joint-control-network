# 07\_节点规划\.md 副本

# 第一版（节点功能）

## Master

职责：

- 设备管理

- 心跳监测

- 发送控制命令

- OLED显示

## JointA

职责：

- 控制电机A

- 读取编码器A

- PID闭环

- 上传状态

## JointB

职责：

- 控制电机B

- 读取编码器B

- PID闭环

- 上传状态

# 第二版本（节点ID分配等）

## 节点编号NodeID

JointA——0x01

JointB——0x02

## 节点类型NodeType

Master——0x01

Joint——0x02
