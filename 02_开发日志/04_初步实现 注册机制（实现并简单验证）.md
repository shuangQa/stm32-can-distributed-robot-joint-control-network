# 04\_初版注册机制（实现并简单验证）

# 设备注册

## 注册程序

```C
void App_Register(void)
{
    Register_Msg_t registerMsg;
    registerMsg.node_id=NODE_JOINTID_JOINT1;
    registerMsg.node_type=NODE_TYPE_MOTOR;

    Protocol_SendRegister(&registerMsg);
}
```

## 运行结果

Master进入接收分析函数的注册报文位置了。

# 主控应答注册

## 主控返回应答程序

```C
void App_ReplyRegisterAck(void)
{
    Ack_Msg_t ack;
    ack.node_id = NODE_ID_MASTER;
    ack.acked_id = CAN_ID_REGISTER;
    ack.seq_num = 0;
    ack.result = 1;

    Protocol_SendAck(&ack);
}

```

## 运行结果

在节点接收中断回调函数里写小灯翻转，没有反应

## 调试过程

开始调试，但是每次设备上电才发送注册信号，接着立马接收主控的应答信号，上电到我点击调试模式的时间可能这个过程已经过去了

方法：使一个引脚PC13为输入模式，然后用导线引出3\.3V电压，条件判断高电平才发送应答信号，在判断内部打断点，不断的将导线点向该引脚（PC13），程序正常运行，多试几次就进入了判断语句内部的断点

步入，逐步找

## 原因分析

主控返回应答，节点接收应答，我用的还是刚刚主控接收注册的代码。

发现错误原因是，节点接收的是应答信号，我的翻转小灯代码还是写在协议层的报文处理函数的判断条件是注册报文的处理后。

修改，翻转成功，实现主控返回应答信号
