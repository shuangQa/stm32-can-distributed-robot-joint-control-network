# 节点对控制报文的处理函数

```C
/*处理控制报文函数*/
void App_HandleControl(const Control_Msg_t *ctrl)
{
    Motor_UpdateControl(ctrl);

    Ack_Msg_t ack;

    ack.node_id = Local_NodeID;
    ack.acked_id = CAN_ID_CONTROL;
    ack.seq_num = ctrl->seq_num;
    ack.result=1;
    Protocol_SendAck(&ack);
}
```
