# 第一版

## 设备信息

设备管理需要存储所有设备的一个总的列表，列表中的每一项代表每个设备（节点）具体的信息，即设备信息

```C
typedef struct{
   uint8_t node_id;   //节点编号
   uint8_t node_type;   //节点类型
   uint8_t online;   //在线状态
   uint8_t state;   //节点运行状态
   }Device_t;
```

## 设备表

```C
#define MAX_DEVICE_NUM 2
Device_t DeviceTable[MAX_DEVICE_NUM];
```

## 处理注册报文

将报文封装成结构体，之后使用结构体对整体操作更清晰，维护扩展也更方便

```C
typedef struct{
   uint8_t node_id;   //节点编号
   uint8_t node_type;   //节点类型
   }RegisterMsg_t;
```

## 处理心跳报文

```C
typedef struct{
   uint8_t node_id;   //节点编号
   uint8_t state;   //节点状态
   }HeartbeatMsg_t;
```

## 发送运动控制报文

```C
typedef struct{
   uint8_t node_id;
   uint16_t target_rpm;   //电机目标速度
   uint8_t enable;   //电机使能
   }ControlMsg_t;
```

## 接收状态报文

```C
typedef struct{
   uint8_t node_id;
   uint8_t actual_rpm;   //电机真实转速
   uint8_t pwm;   //PWM输出
   uint8_t state;   //电机运动状态；
   }StatusMsg_t;
   
```
