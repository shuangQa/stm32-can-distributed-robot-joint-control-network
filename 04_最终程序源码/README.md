# STM32 CAN Distributed Motion Control

This repository contains a two-board STM32F103 project for a small distributed
motor-control system.

## Project layout

- `Master/`: master node, device registration, heartbeat monitoring, status
  collection, and control-command transmission.
- `JointNode/`: motor node, CAN command parsing, encoder speed measurement,
  PI speed control, PWM output, and node state machine.

## CAN application protocol

| CAN ID | Direction | Purpose |
| --- | --- | --- |
| `0x100` | Master -> node | Target RPM, enable flag, sequence number |
| `0x200` | Node -> master | Actual RPM, PWM, state, fault code |
| `0x300` | Node -> master | Heartbeat |
| `0x400` | Node -> master | Node registration |
| `0x500` | Both directions | Acknowledgement |

All application frames use standard 11-bit CAN identifiers and an 8-byte data
field.

## Hardware and software

- MCU: STM32F103
- Framework: STM32 HAL generated by STM32CubeMX
- Build system: CMake
- Control loop: encoder feedback with PI control

The `.ioc` files are included so the peripheral configuration can be reviewed
and regenerated when needed. The generated build directories and binary
artifacts are intentionally excluded from this repository version.
