# 仓库补充材料

这是给仓库补的一层入口说明，目标是让第一次点进来的人，能很快看懂：
这个项目做了什么，系统怎么分工，源码和文档该先从哪里看。

## 建议阅读顺序

1. [项目总览](./项目总览.md)
2. [CAN协议说明](./CAN协议说明.md)
3. [构建与运行](./构建与运行.md)
4. [00_精选调试记录](./00_精选调试记录/精选调试记录.md)
5. [02_开发日志](./02_开发日志/)

## 一句话概括

基于 STM32F103 和 CAN 总线实现分布式机器人关节控制网络，完成主控/关节节点协同、节点注册与心跳管理、状态反馈、PI 调速和 PWM 驱动，并沉淀出完整的调试与优化过程。

## 这个仓库里有什么

- `01_初始方案草稿`：项目定义、系统设计、状态机设计、接口设计等前期方案
- `02_开发日志`：按阶段记录的开发过程
- `00_精选调试记录`：比较有代表性的排障和修正记录
- `03_过程（实验）程序代码`：实验过程中的程序版本
- `04_最终程序源码`：完整的最终源码
- `05_最终程序源码_轻量优化版`：更适合阅读和展示的精简版源码

## 面试时最值得看

- `项目总览.md`：先快速理解系统结构
- `CAN协议说明.md`：再看通信协议怎么组织
- `00_精选调试记录/精选调试记录.md`：最后看你怎么定位问题和修正问题

## 这个项目的主线

- 主控节点负责节点注册、心跳监控、状态汇总和控制命令下发
- 关节节点负责编码器测速、PI 调速、PWM 输出和节点状态管理
- 协议、状态机、调试和源码是连在一起的，不是分散写的几段记录
